Architecture & Fail-Safe Design

5 Pre-Trained Bundled Models

Ships portable SHA-256 JSON artifacts for Gradient Boosting (default), Random Forest, Extra Trees, Logistic Regression, and Decision Tree with zero scikit-learn skew.

Leakage-Free SecretCandidate Contract

Extracts 30 static features from scan-time evidence via SecretCandidate v1.0.0 using masked values and SHA-256 digests without retaining raw secrets.

Fail-Safe Hybrid TriagePolicy

Defaults to advisory scoring (suppress_false_positives=False) and shields CRITICAL detections so real credentials are never silently suppressed.

Polyglot SAST & 8-Ecosystem SCA

Delegates scanning to SIDIK (>=v1.4.0) for 30+ extensions, 19 manifests, and symmetric update-db / db-info offline OSV commands.

Quick Start

# Global install from PyPI (Core SIDIK is installed automatically)
pip install sidik-ml
pip install "sidik-ml[gui]"

# Inspect all 5 bundled Non-ANN models and scan polyglot projects
sidik-ml models
sidik-ml . --fail-on high
sidik-ml . --model random_forest --format html -o ml_report.html

# Sync 8-ecosystem OSV caches and launch Amber Orange TUI / GUI
sidik-ml db-info
sidik-ml update-db --ecosystem npm,go,crates
sidik-ml --gui
